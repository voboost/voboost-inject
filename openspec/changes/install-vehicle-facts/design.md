# Design

The existing resolver, typed facts and bounded read-only NVRAM decoder are shared by installer and explicit diagnostic refresh. Installer publication precedes the init definition. Normal runtime validates and reads the root-owned document; it does not repair or rewrite it. Cached native powertrain admission checks current platform axes. Existing DEX selection remains a trusted installed-profile consumer; this change does not claim unique per-car identity. Host tests and Android/vehicle acceptance are separate.
