# Add the exact VehicleSetting resource owner

## Why

VehicleSetting resources have an independent actual process and cannot use Setting or Launcher proof.

## What Changes

- Add the exact VehicleSetting owner and two signed lexical profiles to the existing closed owner mapping.
- Keep two candidates per owner, independent Setting controls, complete declared-scope diagnostics and six-profile reversible cleanup.

## Impact

Shared root resource mapping, fixed daemon slots, focused tests and current specification. No Java wire, signing, policy, init, QNX transaction or forced process start.
