# Split owner admission from complete-scope readiness

## Why

A nonrunning or unsupported declared process must not prevent the available Setting process from adding Russian after its own actual readback. Complete resource coverage still requires every owner.

## What Changes

- Admit each owner independently after the complete signed payload inventory and its own current resource readback.
- Observe pending, unsupported and complete scope separately without a Java aggregate authority field.
- Revoke cached admissions immediately on a current inventory failure; never revive cancelled results.

## Impact

Daemon resource coordinator, bounded diagnostics and tests. No delivery pair, signature, Java wire, policy, init, QNX transaction or process launch change.
