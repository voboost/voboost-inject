# Voboost Inject Code Style

## Global
- Follows ALL common rules from ../voboost-codestyle/AGENTS.md
- Rust root daemon + C ptrace injector + C++ LSPlant implant; runs as root,
  injects signed agents into Android processes via ptrace (no frida)

## OpenSpec
- Spec-driven; truth is openspec, no code without an applied change, invariants live in specs
- propose -> apply -> archive
- npx @fission-ai/openspec validate <change> --strict
- Every SHALL needs a gate that verifies it; no gate → mark `## Unverified` + reason
- Working artifact exists → find its source first (strings/build-id/git log/PoC dir), reuse that version+patches; don't rebuild from scratch

## Development
- Lines <= 100 chars
- Rust: idiomatic, `cargo fmt` + `cargo clippy --all-targets -- -D warnings`;
  blocking poll loop (std::thread::sleep + libc::signal), no async runtime
- C/C++: uncrustify (config/config-uncrustify.cfg); C++20, c++_static
- `make init` (Rust toolchain + cargo-ndk + NDK r29 + dev keypair)
- `make lint` / `make lint-fix` / `make test`
- Gate from daemon/: `cargo fmt --check && cargo clippy --all-targets && cargo test`

## Architecture (see openspec/specs/ for depth)
- daemon/ (Rust): poll loop, /proc watching, reconcile (maps marker), bitness
  detect, safety (rate-limit + circuit breaker + panic-quarantine), trust
  (ed25519 + sha256), release-manifest verify, OTA self-update, status.
- injector/ (C, ndk-build -> libinjector.a): ptrace attach, remote_call64/32,
  __loader_dlopen of libimplant.so, implant_init call.
- implant/ (C++, ndk-build -> libimplant.so per ABI): ART attach, hidden-API
  exempt, LSPlant init, InMemoryDexClassLoader agent load.
- prebuilt/: generated by `make build-third-party` from third_party/
  submodules (Dobby + LSPlant, NDK r29, c++_static). liblsplt.so removed
  (unused). armv7 libdobby.a is a committed fallback (master Dobby broken for
  armv7 — see build-and-signing spec `## Unverified`).

## Emulator & build env (verified — no need to re-check each session)
- SDK: `$HOME/Library/Android/sdk`; NDK r29:
  `$HOME/Library/Android/sdk/ndk/29.0.14206865` (LSPlant C++23 modules require
  NDK major 29; r27 fails).
- `make build-android` cross-compiles via cargo-ndk (daemon ELF,
  aarch64-linux-android) + ndk-build (native payload). Output:
  `daemon/target/aarch64-linux-android/release/voboost-inject`,
  `implant/libs/{arm64-v8a,armeabi-v7a}/libimplant.so`.
- Emulator: `emulator-5554`, AVD `free`, API 28, `arm64-v8a`, Apple Silicon host.
- NEVER pass `-writable-system` (cold boot never completes on this host); the
  `/system` init hook is NOT used on the emulator — `make emulator-run` starts
  the daemon from the host under `su 0` after `sys.boot_completed=1`.
- `make emulator-run` provisions `/data/voboost-inject` from test/fixtures.
- SELinux is `Enforcing` by default. The committed policy
  (selinux/voboost-inject.te) grants the ptrace allow rules; on Permissive it
  is masked — final validation is on Enforcing hardware.
- Root zone: `/data/voboost-inject` (root:root, 0700) with `manifest.json`/
  `manifest.sig`, `release-manifest.json`/`.sig`, `payload/{abi}/`, `logs/`,
  `run/`, `shared/` (channel B, media_rw_data_file). Status:
  `/data/user/0/ru.voboost/inject-status.json`.
- Daemon logs: `/data/voboost-inject/logs/inject-YYYY-MM-DD.log`.
